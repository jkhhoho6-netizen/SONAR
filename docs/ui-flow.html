화면 연계 및 예외 처리

액터 간 연계 5 · 예외 시나리오 7

액터 간 연계 흐름 — 담당자 화면과 관리자 화면이 맞물리는 지점

1 02_signup 가입 신청→ 27_user_approval 관리자 승인→ 01_login 로그인 가능
2 16_shipment_create 화물 등록→ 28_shipment_approval 등록 승인→ 10_radar 정식 모니터링 대상 전환 승인 전에도 잠정 분석 결과는 즉시 지도에 표시 (점선 마커)
3 23_event_review 이벤트 발행→ 매칭 엔진 재실행→ 10_radar · 11_match_list 영향 건 산출
4 12b_notify_request 대외 알림 요청→ 29_notification_approval 발송 승인→ 18_notification_center 발송 완료 사내 알림은 임계값 초과 시 승인 없이 자동 발송
5 12c_feedback 오탐 신고→ 30_feedback_summary 오탐율 집계→ 26_threshold_config 기준 보정

INVALID_STATE

E-06 · 409
발행 조건 미충족
