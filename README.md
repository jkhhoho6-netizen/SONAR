# SONAR — 해상물류 공급망 리스크 레이더 (설계 검증용 프로토타입)

> 뉴스는 **바다가 위험하다**고 말하지만, **내 화물이 위험한지**는 말해주지 않습니다.
> SONAR는 리스크 정보와 내 운송 건 사이의 **연결 부재**를 해결합니다.

## 실행

```bash
cd app && npm start
```

의존성 설치가 필요 없습니다 (Node 내장 `http` 모듈만 사용). 브라우저에서 <http://localhost:4173> 접속.

## 배포 (지인 피드백용)

서버 없이 **브라우저 안에서 백엔드가 그대로 도는 모드**를 지원합니다. 라우터·핸들러·시드 데이터는
Node 판과 **동일한 `src/` 모듈**을 재사용하므로 두 모드의 동작이 갈리지 않습니다.

| 모드 | 진입점 | API 처리 | 용도 |
|---|---|---|---|
| 서버 | `/` (`public/index.html`) | `fetch` → Node HTTP 서버 | 로컬 개발, API 명세 검증 |
| 임베디드 | `/embedded.html` | `public/js/embedded-server.js` (브라우저 내 디스패치) | 정적 배포, 링크 공유 |

전환은 `window.SONAR_EMBEDDED` 플래그 하나로 이루어집니다 (`public/js/api.js`의 전송 계층).

```bash
# 임베디드 모드 로컬 확인
cd app && npm start   # → http://localhost:4173/embedded.html
```

임베디드 모드는 데이터가 **메모리에만** 있으므로 보는 사람마다 독립적이고, 새로고침하면 초기 상태로
돌아갑니다. 피드백용으로는 오히려 안전합니다 (서로의 입력이 섞이지 않음).

### 지도

외부 타일 서버에 의존하지 않습니다. Natural Earth 110m 국경 데이터(`public/data/world.geo.json`,
167KB)를 Leaflet이 직접 벡터로 그립니다. 오프라인에서도 동작하고 API 키가 필요 없습니다.

3. 우선순위 1위(**SNR-2026-0005**) 클릭 → **영향 건 상세**
   - 리스크 점수 79점의 산출 근거 3계수 분해
   - 대응 시나리오 선택 → **조치 등록** (FR-06)
   - **고객 알림 발송 요청** → 대외 건이므로 관리자 승인 대기 (FR-07)
4. **화물 등록** → 부산→로테르담, 가액 190만 달러, 납기 여유 3일
   - 경유 요충지 자동 산출 (대만해협 · 말라카 · 바브엘만데브 · 홍해 · 수에즈)
   - 등록 즉시 **3건 매칭, 최고 82점** → 레이더에 즉시 반영
5. `admin@sonar.io` 로 전환 → **운영 대시보드**
   - FR-01 → FR-02 → FR-03 파이프라인 현황
6. **이벤트 모니터링** → "어떤 뉴스로 · 어느 지역에 · 어떤 위험도"
   - 홍해 이벤트 열기 → UKMTO 원문과 LLM 정형화 결과 대조
   - 심각도 4→5 수정 / 영향 지역 추가 → **재매칭** 실행 → 영향 건 수 변화 확인
   - 기각 사례(`[미확인] 수에즈 운하 전면 폐쇄`) 확인 → 소셜 소스 신뢰도 0.22로 걸러짐
7. **화물 등록 승인** → 4번에서 등록한 건 승인 → 잠정(점선) → 정식 모니터링 전환
8. **알림 발송 승인** → 3번의 대외 발송 건 승인 → 발송 완료
9. **임계값 설정** → HIGH 하한만 50 → 45로 바꿔 저장 → 구간 불연속 검증 오류 (E-06)
   - MEDIUM 상한도 44로 함께 조정 → 저장 성공 → 전체 27건 등급 즉시 재계산 (HIGH 3 → 5건)

## 리스크 점수 산식 (FR-04)

```
riskScore = 100 × severityFactor × exposureFactor × confidenceFactor    (0~100)

severityFactor   = (이벤트 심각도 / 5) × 0.7 + (지역 영향도 / 5) × 0.3
exposureFactor   = 0.4 + 0.6 × (가액정규화 × 0.35 + 납기긴급도 × 0.40 + 경로경직성 × 0.25)
confidenceFactor = LLM 확신도 × 수집 소스 신뢰가중치

  가액정규화   = min(화물가액 / 2,000,000 USD, 1)
  납기긴급도   = 1 - min(납기여유일수 / 21, 1)
  경로경직성   = 대체경로 있음 0.35 / 없음 1.00

등급 : 0-24 LOW · 25-49 MEDIUM · 50-74 HIGH · 75-100 CRITICAL  (관리자 변경 가능)
```

## 매칭 규칙 (FR-03)

이벤트의 **영향 지역** × 화물의 **운송 구간** × **일정 겹침** 3중 교집합으로 산출합니다.

| 매칭 근거 | 조건 |
|---|---|
| `CHOKEPOINT_TRANSIT` | 화물 경유 요충지의 통과 예정일이 이벤트 영향 기간 내 |
| `PORT_CALL` | 배정 항차의 중간 기항일이 이벤트 영향 기간 내 |
| `ORIGIN` | 출발항이 영향 항만이고 ETD가 영향 기간 내 |
| `DESTINATION` | 도착항이 영향 항만이고 ETA가 영향 기간 내 |

하나의 (이벤트, 화물) 쌍에 대해 **가장 높은 점수의 근거 1건**만 대표로 저장합니다.
